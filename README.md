# Student Management System

A beginner-friendly console-based application
developed using Java.

## Features
- Add student records
- View all students
- Search for students
- Delete student records
- Exit the application

## Technologies Used
- Java
- ArrayList
- Scanner
- Object-oriented programming basics

## How to Run
1. Download Main.java
2. Compile using javac Main.java
3. Run using java Main
